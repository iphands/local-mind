## 7 · permanent changes made because of this
  - t3-model-file-poc.sh: export PYTHONDONTWRITEBYTECODE=1 before importing the tree, plus a
    post-run POC_TREE_BYTECODE check that exits 3 (a new code: the experiment damaged its

    next occurrence says what it is instead of showing up as a hash nobody recognises.
  - the plan's one freeze-check is now three legs: tracked contents, file count = 862, and
    'git status --porcelain --ignored' empty. The count and the status legs are the ones git
    diff cannot substitute for.
